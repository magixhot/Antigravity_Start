# Навык: Компиляция базы знаний (Memory Compile)

**Цель:** Прочитать информацию из `raw/daily/`, обновить или создать статьи в `wiki/` (concepts, entities), а также обновить `wiki/index.md` и `wiki/log.md`. Весь процесс строго на русском языке.

## Инструкции по выполнению

1. **Чтение исходных данных:**
   - Найдите самый свежий файл(ы) логирования в `raw/daily/` (например `raw/daily/YYYY-MM-DD.md`), который вы будете компилировать.
   - Прочитайте `wiki/index.md` чтобы понять, какие термины и статьи уже существуют.

2. **Обработка данных (The Compiler Logic):**
   - По каждому блоку информации из лога решите:
     - Описывает ли это уже существующую концепцию/сущность из `wiki/index.md`? Если да — обновите этот файл.
     - Это совершенно новая важная тема? — Создайте новый файл. 
     - При создании/обновлении используйте короткие *Obsidian wikilinks* вида `[[Название Статьи]]`.

3. **Формат создаваемых файлов (`wiki/concepts/` или `wiki/entities/`):**
   ```markdown
   ---
   title: "Название концепта/сущности"
   sources: ["raw/daily/YYYY-MM-DD.md"]
   updated: YYYY-MM-DD
   ---
   # Название

   [Энциклопедичное описание из 2-3 предложений]

   ## Ключевые моменты
   - [Факты]

   ## Связанные темы
   - [[Другая статья]]
   ```

4. **Обновление индекса и лога:**
   - Добавьте новые созданные файлы в `wiki/index.md` (сохраняя категоризацию на Entities и Concepts).
   - Внесите запись об операции в `wiki/log.md`:
     `## [YYYY-MM-DD HH:MM] compile | Обработан файл daily/YYYY-MM-DD.md`

5. **Отчет:**
   - Скажите пользователю: "Компиляция успешно завершена. Были созданы новые статьи: [Список], обновлены: [Список]."
