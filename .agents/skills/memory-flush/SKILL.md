# Навык: Сохранение памяти сессии (Memory Flush)

**Цель:** Автоматически проанализировать текущий лог беседы с пользователем, извлечь из него самую важную информацию (принятые решения, проблемы, решения проблем, новые идеи или знания) и сохранить это в виде хронологической записи в `raw/daily/`.

## Инструкции по выполнению

1. **Прочитайте лог текущей сессии:**
   В Antigravity (Gemini) системный лог всей текущей беседы находится по пути:
   `$appDataDir/brain/<conversation-id>/.system_generated/logs/overview.txt`
   Если вы не можете получить этот лог напрямую, используйте контекст, который вы уже знаете (ваше контекстное окно) за текущую сессию.

2. **Извлеките ключевую информацию:**
   Составьте резюме сессии, сфокусировавшись на:
   - Какие решения были приняты?
   - Какие ошибки возникли и как они были решены (важно для устранения неполадок в будущем)?
   - Какие новые технологии, команды, концепции обсуждались?
   - **Не пишите банальный текст** («мы поздоровались», «пользователь попросил»). Только факты: "Решили использовать X вместо Y потому что Z".

3. **Сформируйте запись:**
   Используйте следующий формат:
   ```markdown
   ## Сессия: [HH:MM] - Краткое название темы

   **Контекст:** Кратко о том, над чем работали.
   
   **Ключевые решения/знания:**
   - [Факт 1]
   - [Факт 2]
   
   **Выводы (Lessons Learned):**
   - [Вывод 1]
   ```

4. **Запишите в ежедневный файл:**
   - Вычислите текущую дату (YYYY-MM-DD).
   - Проверьте наличие файла `raw/daily/YYYY-MM-DD.md`.
   - Если файл не существует, создайте его: `# Daily Log: YYYY-MM-DD\n\n`.
   - Добавьте вашу сформированную запись в конец этого файла.
   - **ВАЖНО:** Все записи должны быть строго на русском языке.

5. **Отчет пользователю:**
   - После успешного сохранения скажите: "Запись сессии успешно добавлена в `raw/daily/YYYY-MM-DD.md`. Вы можете запустить загрузку в базу (SKILL: memory-compile), когда будете готовы."
