# Навык: Поиск по базе (Memory Query)

**Цель:** Четко и аргументированно ответить на сложный вопрос пользователя, основываясь исключительно на тех знаниях, которые сохранены в `wiki/`.

## Инструкции по выполнению

1. **Чтение индекса:**
   - Начните с чтения `wiki/index.md`. Не полагайтесь на общие знания LLM — ответ должен быть связан с конкретной базой проекта.
   
2. **Отбор источников:**
   - На основе индекса решите, какие 2-6 статей нужно прочесть целиком, чтобы ответить на запрос пользователя.
   - Прочитайте эти статьи.

3. **Синтез ответа:**
   - Сформулируйте ответ на русском языке.
   - Каждое утверждение должно сопровождаться ссылкой на источник `[[Название Статьи]]` (Obsidian wikilink).
   
4. **Опциональное сохранение в Q&A (по запросу):**
   - Если пользователь попросил "навсегда сохранить ответ" (или указал флаг-намерение сохранить), создайте новый файл в `wiki/qa/вопрос-кратко.md` в таком виде:
     ```markdown
     ---
     title: "Q: [Сам вопрос]"
     consulted: ["[[Статья 1]]", "[[Статья 2]]"]
     filed: YYYY-MM-DD
     ---
     # Q: [Сам вопрос]
     
     [Ваш ответ]
     ```
   - Затем обновите `wiki/index.md` и `wiki/log.md`, добавив запись о сохраненном Q&A.

5. **Отчет:**
   - Отдайте ответ пользователю в чат. Если он был сохранён, сообщите, где он лежит.
